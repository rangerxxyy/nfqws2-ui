# v1.9.3 — SNI-проверка по необходимости

## Изменения

- SNI-проба выполняется только при сетевой ошибке прямого HTTPS-запроса для домена, отличного от контрольного имени `example.com`.
- Если сайт уже отвечает напрямую, цель введена как IP или запрошено контрольное имя, строка SNI помечается как ненужная с пояснением вместо ложной ошибки.
- При реальном отказе подключения SNI-проверка и потоковое отображение результата сохраняются.

## Проверки

- 403 frontend-теста.
- TypeScript typecheck и production build.
- Rust fmt, полный тестовый набор и Clippy.
- Release workflow проверяет shell-скрипты, аудит зависимостей и ARM64 Linux musl сборку.
