# v1.2.3 — Профили, резервные копии и журналы

- В конструкторе заменено добавление пустого шага на понятное действие «Добавить стратегию» с выбором из русскоязычного списка.
- Добавление стратегии изменяет только выбранный профиль в `NFQWS_ARGS_CUSTOM`; встроенные UDP, QUIC и HTTP/HTTPS группы остаются привязаны к своим переменным конфигурации.
- В «Резервных копиях» можно выключить автоматические копии перед изменениями и ежедневное расписание. Ручные снимки остаются доступны; перед восстановлением сохраняется страховочная копия. Список стал компактнее.
- В «Журнале» автообновление можно приостановить, не теряя ручное обновление.
- Исправлено переполнение очереди уведомлений, которое могло удалить постоянный статус проверки сайта.

## Проверки

- На ПК: 302 frontend-теста, 340 Rust-тестов, проверка TypeScript, production-сборка и Clippy.
- ARM64 сборка и установочный архив проверяются релизным workflow GitHub Actions.
- Работающий роутер не обновлялся этим кандидатом; изменения на устройстве не применялись.
