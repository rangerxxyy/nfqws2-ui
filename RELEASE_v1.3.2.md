# v1.3.2 — Профили, списки и сетевые настройки

- Исправлена сверка списков в диагностике сайта: учитываются только файлы, используемые активными аргументами nfqws2.
- Упрощён выбор `ISP_INTERFACE`: один список обнаруженных интерфейсов, ручной ввод по запросу и сохранение настроенного интерфейса, которого нет среди обнаруженных.
- Переключатель режимов конструктора профиля перемещён в заголовок и получил скользящий индикатор. Переименование профиля доступно через кнопку-карандаш.
- Вкладки списков показывают имена файлов; справка появляется при наведении через три секунды. Повышена читаемость списков и панели редактора.

Frontend: 330 тестов, typecheck и production build. Backend и сборка для роутерной архитектуры проверяются release workflow.
