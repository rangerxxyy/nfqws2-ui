# v1.2.8 — Удобнее читать журнал и пользоваться подсказками

- При первом открытии журнала показываются последние строки.
- Автообновление удерживает просмотр у конца, пока пользователь читает новые записи; при прокрутке вверх позиция сохраняется.
- Подсказки действий остаются доступны при клавиатурной навигации и не всплывают после касания на телефоне.
- Сокращение встроенного списка профилей проверяется отдельно; пользовательские профили с совпадающими именами остаются доступными.

## Проверки

- Frontend: 310 тестов, TypeScript-проверка и production-сборка прошли локально.
- Backend: `cargo test --locked` прошёл локально; кэш тестовой сборки находится на диске E: и будет удалён после публикации релиза.
- GitHub Actions выполняет Linux ARM64 cross-build и повторяет релизные проверки.
- Проверку на роутере проводит пользователь; удалённое управление роутером не выполнялось.
