# v1.5.1 — Улучшения истории, ASN и тем оформления

## Изменения

- **Стратегии сообщества:** автоматическое определение провайдера при первом открытии выполняется только при отсутствии сохранённого ASN. Добавлено компактное пустое состояние; пустые группы протоколов не занимают место, имя провайдера показано рядом с ASN.
- **История изменений:** список стал шире и лучше читается на настольных и узких экранах. Проверка целостности объектов истории сверяет распакованное содержимое с адресным SHA-256.
- **Безопасность группового отката:** все версии проверяются до первой записи, конкурентные изменения блокируются на всю операцию, перед откатом создаётся страховочная копия. Если любой шаг завершится ошибкой, все файлы восстанавливаются; отметки об отмене записываются атомарно.
- **Тема интерфейса:** включённые checkbox и их фокус-состояние следуют выбранным теме и акцентному цвету.

## Проверки

- Frontend: 355 тестов, TypeScript typecheck и production build.
- Rust: 395 тестов, `cargo fmt --check`, Clippy с `-D warnings`; `cargo check --target aarch64-unknown-linux-musl --locked`.
- GitHub release workflow на коммите кандидата завершился успешно: прошли shell/preflight-проверки, `cargo audit`, `pnpm audit --prod`, `cross test`, статическая ARM64/musl-сборка, ELF-проверки, упаковка и проверка SHA-256.
- На роутере проверены ARM64-архитектура, health endpoint и главная страница установленной v1.5.0. Собранный бинарник v1.5.1 отдельно запущен с `--version` во временном каталоге: `nfqws2-ui 1.5.1`. Сжатый архив и распакованный бинарник удалены; работающий сервис не заменялся.
