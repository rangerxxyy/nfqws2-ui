# v1.5.0 — История изменений, ASN и стратегии сообщества

## Что добавлено

- **Стратегии сообщества.** Компактный экран показывает стратегии для выбранного ASN провайдера из открытой базы `zemidala/nfqws2-strategies`. ASN можно определить автоматически или задать вручную. Данные кэшируются; показаны TLS/HTTPS и HTTP, подтверждения и неудачные попытки. Каждую стратегию можно отдельно проверить на роутере; она не вносится в основной конфиг без отдельного предпросмотра и подтверждения. После теста можно открыть заполненную форму GitHub для подтверждения, публикации или сообщения о неудаче. IP-адрес пользователя в форму не включается.
- **Стратегии сообщества в автоподборе.** По отдельному флажку подходящие свежие кандидаты добавляются к проверке одного или нескольких сайтов, проходят повторную проверку на установленной версии nfqws2 и только затем могут быть применены через существующий предпросмотр.
- **История изменений.** Backend сохраняет версии `nfqws2.conf` и `.list` при изменениях панели и внешних изменениях, строит diff, позволяет откатить отдельное изменение, отменить последнюю операцию и вернуть файлы к исходному состоянию. Групповой откат сверяет актуальные хэши и проверяет перезапуск службы; исходная версия списка файлов восстанавливается без удаления новых файлов, которых не было при установке.
- **ASN и диагностика передачи.** Итог короткого HTTP-ответа формулируется как «Ответ получен», не выдавая его за подтверждение полной передачи 16 КБ. Добавлены повторные измерения в спорном диапазоне, безопасное добавление подтверждённой ASN-сети к совместимому профилю с diff и резервной копией, а также ограниченное обновление управляемых ASN-списков.
- **Мониторинг и интерфейс.** Проверки мониторинга ограничены тремя одновременными сайтами. Восстановлена подсветка выбранной Lua-функции и тематические полосы прокрутки; сохранены улучшения узкой сетки конструктора и стабильности редактора.

## Проверки

- Frontend: 351 тест, TypeScript typecheck, production build, production dependency audit.
- Rust: 161 тест библиотеки и 176 тестов backend; integration suites: freeze 14, service status 3, strategy picker 20, transfer diagnostics 16; formatting и Clippy без предупреждений.
- Installer/updater preflight и сборка ARM64 выполняются release workflow. Результаты проверки и smoke-test на роутере будут отражены после проверки установленной сборки.
