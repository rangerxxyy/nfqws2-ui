# План: варианты оформления UI

## Цель

Дать пользователю несколько компактных способов менять акцентные цвета, статус-бар и расположение навигации, сохраняя доступ ко всем разделам и настройки между перезапусками панели.

## Подход

- Хранить палитру, режим статус-бара и раскладку рядом с текущими настройками темы.
- Отдельно расширить API настроек на роутере с default для старых файлов `appearance.json`.
- Новые раскладки делать CSS-пресетами поверх существующей разметки: боковая панель справа, горизонтальное меню сверху, плиточная навигация.
- DNS-имена IP выводить в существующей строке DNS; доменные цели показывают IP, отдельный PTR-ряд не используется.

## Критерии проверки

- Старый формат настроек загружается со значениями по умолчанию.
- Новые параметры синхронизируются с backend и восстанавливаются при запуске.
- Переключение раскладок сохраняет все разделы, кроме уже существующего поведения компактного режима.
- Диагноз домена показывает IP, диагноз IP показывает найденное PTR-имя внутри DNS-строки.
- Frontend tests/build и backend fmt/tests/clippy проходят.
