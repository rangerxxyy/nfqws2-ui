# nfqws2-ui v0.6.0 UX and behavior design

## Goal

Polish the existing router UI for clear status, feedback, configuration reading, diagnostics, and mobile use while keeping existing service and configuration operations intact.

## Decisions

- Keep the current React shell and delegated TypeScript behavior; do not add a large UI dependency for isolated controls.
- Reuse existing action tooltip, styled-select, toast, diagnosis presentation, and appearance mechanisms where present.
- Keep service actions state-driven: the control icon, accessible name, tooltip, and action must all reflect whether nfqws2 is running.
- Render GitHub release Markdown as safe semantic HTML, preserving links, lists, emphasis, headings, and code without injecting raw HTML.
- Diagnosis progress is presentation feedback for the existing ordered backend checks; it must not add network probes or delay the actual diagnosis.
- Router checks must be read-only or limited to a single UI health/asset check. Do not run network stress, strategy batches, service restarts, or installs on the user's router as part of this release.
- Preserve all navigation sections in mobile layout; compact appearance may retain its existing explicit hide behavior only where that setting is intended.
- The v0.6.0 GitHub release description must cover only these 13 requested areas.

## Scope

All 13 items in the v0.6.0 request: service status button, visual audit, lifecycle notices, XKeen-style update notice and Markdown, enabled-by-default config structure, updater icon alignment, sequential diagnosis presentation, delayed custom tooltips, animated checkboxes, clickable appearance cards, distinct terminal commands, conditional Telegram fields, and clearer compact strategy results.

## Verification

Run focused web tests for changed behavior, the web production build, backend formatting/checks and project CI tests; exercise Chromium, Firefox, and mobile viewport where available. Router validation is limited to safe read-only access and must be reported separately from UI simulation.
