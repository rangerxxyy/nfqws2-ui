# Цель проекта nfqws2-ui

Создать с нуля безопасную, устанавливаемую локально веб-панель для управления nfqws2 на Keenetic/Entware. Основной стек: TypeScript для веб-интерфейса, Rust для локального API и системных операций, POSIX Shell только для установки, удаления и init-интеграции.

Старый удалённый репозиторий и его история не восстанавливаются. Новая кодовая база начинается в чистом репозитории. Изученные проекты служат источниками требований и поведения; код переносится только при осознанной необходимости и с соблюдением лицензий.

Приоритеты: безопасность и сохранность конфигурации → достоверный статус и управление службой → сборка и воспроизводимая установка → тесты → UX и расширенные функции. Нельзя заявлять о поддерживаемой платформе или выпущенном релизе без проверки соответствующих артефактов и среды.

## Цель первого релиза

Подготовить минимальный проверенный выпуск, содержащий TypeScript UI, Rust API, POSIX `install.sh`, аутентификацию, статус/запуск/остановку/перезапуск службы nfqws2, безопасное чтение и запись конфигурации с резервной копией, просмотр логов, порт по умолчанию 1002 с поиском следующего свободного, адаптивную компоновку и четыре локали. Непроверенные действия и платформы остаются явно ограниченными.
