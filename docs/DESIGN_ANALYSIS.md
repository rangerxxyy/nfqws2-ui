# Разбор предоставленного HTML-дизайна

Файл `nfqws2_ui_web_management_panel.html` используется как визуальный ориентир, а не как готовая реализация backend.

- Тёмная панель управления с постоянным левым меню, брендингом nfqws2 и большой рабочей областью.
- Сине-графитовый фон, синие акценты и контрастные состояния службы; карточки с мягкими радиусами и тонкими границами.
- На обзоре приоритетны состояние службы, действия, версия/порт, CPU и память.
- Разделы сгруппированы вокруг конфигурации, списков, диагностики, мониторинга, снимков и журналов.
- Сохранять читаемую иерархию и адаптацию для узкого экрана; навигация превращается в компактное мобильное меню.
- Интерактивные значения из прототипа нельзя выдавать за реальные системные данные. Продакшен-запросы идут только в Rust API.
- Внешние CDN (Tailwind/шрифты) не обязательны для работы панели; сборка должна быть автономной.

Планируемая реализация использует собственные CSS-токены и простые CSS-переходы, `prefers-reduced-motion` и локальные системные шрифты без тяжёлых runtime-зависимостей.
