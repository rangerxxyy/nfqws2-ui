# v1.5.5 — Интерфейсы и стратегии сообщества

## Изменения

- В быстрых параметрах `ISP_INTERFACE` доступны обнаруженные системой интерфейсы. В конце списка добавлен пункт ручного ввода имени, чтобы можно было указать интерфейс, отсутствующий в обнаружении. Имя проверяется перед обновлением черновика конфигурации.
- В конструкторе стратегий убрана видимая подпись «Свой» рядом с CUSTOM; предупреждения профиля сохранены.
- В разделе стратегий сообщества пустое состояние стало компактным текстом без дополнительной карточки. Кнопки провайдера и формы редактирования увеличены и используют общий шрифт панели.

## Проверки

- 383 frontend-теста.
- TypeScript typecheck.
- Production build.
- Полный release workflow дополнительно выполняет проверки backend, установщика и ARM64-сборку.
