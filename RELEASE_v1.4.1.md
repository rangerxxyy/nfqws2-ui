# v1.4.1 — Выбор функции и цвета темы

## Изменения

- Lua-функция в конструкторе стратегий выбирается общим popup-select каталога параметров: совпадают палитра и механика выбора, а смена функции сохраняет остальные аргументы шага.
- Полосы прокрутки окрашиваются по выбранному акценту и теме — тёмной, светлой или neon. Толщина и поведение прокрутки сохранены.
- Каталог параметров Lua игнорирует комментарии и строковые литералы, чтобы не показывать ложные `desync.arg`.
- После успешного обновления блокируется повторный запуск, пока панель не перезагрузится.

## Проверки

- Frontend: 340 тестов Vitest, TypeScript typecheck и production build.
- Backend: 347 Rust unit/integration tests, `cargo fmt --check`, Clippy и release build.
- Linux ARM64 пакет проверяется release workflow GitHub Actions. Роутер пользователь проверяет самостоятельно.
- Preview подключался к локальному API v1.2.2. Визуальный аудит узкого viewport и проверка внешнего поведения scrollbar не подтверждены; роутер не тестировался.
