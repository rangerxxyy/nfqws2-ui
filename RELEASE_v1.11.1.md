# v1.11.1 — Упрощённый режим больших конфигураций

Для конфигураций длиннее 200 КБ редактор отключает синтаксическую подсветку и колонку номеров строк, повторяя проверенный режим Zemidala для больших текстов. Режим включается и отключается автоматически при пересечении порога; содержимое можно редактировать и выделять как обычно.

Проверки перед публикацией: frontend tests, TypeScript и production build; release workflow запускает Rust, installer, security audit и ARM64 cross-build.
