# v1.9.5 — Читаемые результаты диагностики

## Изменения

- Текст результата и его время выполнения разделены отступом и тонкой вертикальной линией, поэтому DNS, TCP, HTTP и остальные измерения не сливаются.
- Live-список и итоговый отчёт выводят описание до времени выполнения в одинаковом порядке.
- На странице стратегий сообщества убраны поле ручного домена и пустая карточка без стратегий. Для стратегии без целевого домена сайт вводится в форме автоподбора.

## Проверки

- 404 frontend-теста.
- TypeScript typecheck и production build.
- Rust fmt, полный тестовый набор и Clippy.
- Release workflow проверяет shell-скрипты, аудит зависимостей и ARM64 Linux musl сборку.
