# v1.11.7 — Корректная проверка неподключённых списков

Пользовательские файлы в `lists/` больше не получают ошибку проверки формата, если конфигурация однозначно показывает, что они не используются. Для активных и неоднозначных ссылок проверка сохраняется для всех видов `hostlist` и `ipset`. Если конфигурация недоступна или не читается, панель продолжает проверять содержимое.

В интерфейсе списка отображается, выполняется ли проверка при сохранении. История изменений отдельно сохраняет строгую проверку перед откатом пользовательских файлов.

Проверки: 428 frontend-тестов, production-сборка, `cargo fmt --all -- --check` и полный `cargo test --locked`.
