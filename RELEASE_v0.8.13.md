# v0.8.13 — Выбор повторов при проверке чужого конфига

- В проверке стороннего `.conf` добавлен выбор от 1 до 5 повторов, по умолчанию 3 — как в Zemidala.
- Результат помечается подтверждённым только при успехе всех выбранных запросов; после первой сетевой ошибки повторы прекращаются.
- На сервере число повторов ограничивается диапазоном 1–5 даже при некорректном API-запросе.

## Проверки

- Backend unit-тесты проверяют диапазон, значение по умолчанию, успешные и fail-fast серии.
- Web-тесты проверяют передачу выбранного значения API и наличие селектора в панели.
- Полный Rust suite, форматирование, Clippy; Web-тесты, проверка типов и production-сборка.
- Физический роутер недоступен в этой среде; release CI собирает ARM64-версию.
