# v0.9.3 — Повторные проверки и отчёт для помощи

- Исправлено сворачивание блоков «Текущая конфигурация» и «Проверяемая конфигурация»: состояние каждой карточки сохраняется, пока панель обновляет результаты проверки.
- Рядом с доменом показано число успешных запросов из общего числа, например `2/3 успешных`, и среднее время успешных запросов, если backend получил измерение.
- Повторы по-прежнему останавливаются после первой неудачи. Подсчёт попыток и времени соответствует проверке конфигураций в Zemidala.
- Добавлена страница «Отчёт для помощи». Сводку можно проверить, скопировать или скачать вручную; имена сайтов скрываются по умолчанию. Содержимое конфигурации и списков, токен Telegram и вывод команд не включаются.

## Проверки

- Frontend: тесты, TypeScript typecheck и production build.
- Backend: Rust tests, formatting и Clippy.
- Shell/installer preflight и проверка структуры release package выполняются релизным GitHub Actions workflow.
- Проверка на физическом роутере не проводилась.
