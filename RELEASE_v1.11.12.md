# v1.11.12 — Lua-предупреждения перед применением конфигурации

Перед применением конфигурации панель дополнительно проверяет литеральные `--lua-desync` по каталогу Lua-функций, который nfqws2 сообщает для установленной версии. Если обязательный параметр пропущен или указан неизвестный ключ, предупреждение появится в подтверждении вместе с номером строки. Это предупреждение не блокирует запись: пользователь может продолжить после проверки.

Shell-переменные не раскрываются и не исполняются. Аргументы, которые находятся после `#`, не считаются действующими Lua-стратегиями и не создают ложных предупреждений.

Сверено с Zemidala: обязательные и неизвестные Lua-параметры отмечаются при проверке конфига. Проверки релизного набора: полный frontend suite, TypeScript, production build, Rust suite, `cargo fmt --check`, Clippy, cargo audit и shell preflight.
