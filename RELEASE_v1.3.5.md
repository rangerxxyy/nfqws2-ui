# v1.3.5 — Мобильный конструктор и доступность select

- Удалены курсор захвата и `touch-action:none` с ручки стратегий. На узких экранах ручка скрывается, карточки переходят на компактную сетку из номера и содержимого, а вертикальная прокрутка пальцем не блокируется. Перетаскивание свободной области карточки на устройствах с поддержкой HTML5 drag-and-drop сохранено.
- Кастомный выпадающий список теперь закрывается при уходе клавиатурного фокуса за его пределы. Tab больше не оставляет раскрытое меню на экране.

Проверки перед выпуском: 337 frontend-тестов, TypeScript typecheck, production build, Rust tests/clippy/fmt и release workflow GitHub Actions. Физический роутер не проверялся; пользователь проверит устройство самостоятельно.
