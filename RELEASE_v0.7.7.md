# nfqws2-ui v0.7.7

## Диагностика ответов API

- Если API вернул HTML или обычный текст вместо JSON, интерфейс показывает короткий фрагмент ответа, чтобы было проще определить источник ошибки.
- Обработка одинаково работает для обычных запросов и загрузки архива снимка для восстановления.
- Добавлены регрессионные тесты для HTTP 200 с HTML и HTTP 500 с текстовой ошибкой.
