# v1.11.3 — Стабильное выделение и подсветка видимых строк

Редакторы конфигурации используют настройки CodeMirror из XKeen UI для выделения: отключены контекстные лигатуры, которые могли менять ширину символов, и вторая нативная заливка браузера. Подсветка синтаксиса теперь пересчитывается только для видимых строк при вводе или прокрутке.

Проверки перед публикацией: 427 frontend-тестов и production build. Release workflow проверит backend, установщик и ARM64-сборку.
