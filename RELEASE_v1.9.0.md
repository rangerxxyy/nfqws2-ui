# v1.9.0 — Надёжные кнопки подтверждения

## Изменения

- Кнопки «Отмена» и «Продолжить» в диалоге проверки конфигурации теперь имеют собственные обработчики событий и не зависят от общего маршрутизатора кликов.
- Кнопки подтверждения исключены из глобальной блокировки busy-состояния. «Отмена» остаётся доступна, а «Продолжить» перед записью повторно проверяет черновик и текущую ревизию конфигурации.
- Добавлена регрессионная проверка на прямую привязку действий и исключение из общей блокировки.

## Проверки

- 399 frontend-тестов.
- TypeScript typecheck и production build.
- Rust `cargo fmt --check`, полный Rust test suite и `cargo clippy --all-targets -- -D warnings`.
- Release workflow проверяет shell-скрипты, аудит зависимостей и сборку ARM64 Linux musl.
