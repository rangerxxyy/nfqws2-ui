# nfqws2-ui v1.1.0 — Профили, резервные копии и журналы

- Разделы «Сообщество» и «ASN» временно удалены; планируется вернуть их позже.
- Добавлен редактор runtime-профилей nfqws2: просмотр штатных групп и управление пользовательскими профилями из `NFQWS_ARGS_CUSTOM`.
- Подключён раздел «Резервные копии»: создание, восстановление, удаление локальных копий и скачивание.
- Добавлен «Журнал изменений» с версиями UI и перечнем изменённых файлов.
- Добавлен «Журнал» событий nfqws2-UI и nfqws2 с поиском, автообновлением и скачиванием.
- Пункт 6 исходного ТЗ отсутствует; дополнительных требований для него не предполагалось.

Проверка на ПК выполнена. Проверка на роутере пока не завершена: SSH-доступ к устройству не подтверждён.
