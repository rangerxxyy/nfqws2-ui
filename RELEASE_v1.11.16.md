# v1.11.16 — Единый интерфейс и быстрая диагностика

## 1. Палитра конфигурации

Сверена подсветка конфигурации с v1.11.9 и текущей версией. Цветовые классы и CSS-переменные уже сохраняли подсветку значений и синтаксиса; регресс не подтвердился, поэтому стилевой откат не понадобился.

## 2. Списки IP и домены

Выпадающие меню и селекторы используют палитру активной темы. Выбранные строки для удаления получают сдержанный красный фон и границу.

## 3. Кнопки выбора релизов

При наличии нового релиза кнопки UI и nfqws2 показывают анимированную градиентную рамку. Системная настройка уменьшения анимации отключает движение.

## 4. Выбранный релиз

Маркер выбранной версии заменён на компактный радиоиндикатор с кольцом и цветным центром.

## 5. История изменений

Убрано ручное обновление, уменьшен верхний отступ, верхние действия получили SVG-иконки проекта. Просмотр diff открывается плавным аккордеоном и загружает содержимое только при первом раскрытии.

## 6. Проверка сайта

Новую проверку можно запустить, пока предыдущая ещё работает. Предыдущий SSE-запрос прерывается через `AbortController`; события и результаты старого запуска не перезаписывают состояние нового.

## 7. Конструктор стратегий

Убрана лишняя минимальная высота рабочей области, список профилей стал компактнее, а шаги и параметры лучше выравниваются на узких экранах.

## 8. Общие стили

Для контролов закреплён единый sans-шрифт, выпадающие меню учитывают dark/light/neon палитры, статусная строка уплощена. DPI Lab скрыта из навигации до дальнейшей работы.

## Проверка

- Frontend: 473 теста прошли; production build собрался.
- Backend: `cargo build` прошёл.
