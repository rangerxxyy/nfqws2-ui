# v1.12.3 — Совместимость release-проверки

Включает улучшения v1.12.2: кнопки «Сохранить» и «Применить» приглушаются, если данные не менялись, и снова активируются при изменениях.

## Исправление CI

- Для функций очистки, вызываемых POSIX shell traps, добавлено точечное подавление предупреждения ShellCheck `SC2329`. Это устраняет ошибку release workflow на новой версии Ubuntu без изменения поведения скриптов.

## Проверки

- Release workflow запускает ShellCheck, frontend и Rust тесты, production-сборку и ARM64 cross-build перед публикацией пакета.
- Проверка на Netcraze Hopper NC-3811 не проводилась.
