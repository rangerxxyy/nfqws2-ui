# v1.3.0 — Фильтры профилей и точнее диагностика передачи

- В конструкторе профилей доступны выбор протокола из каталога nfqws2 и добавление UDP-портов или диапазонов. Кнопка добавления UDP-фильтра больше не выходит за границы.
- Таблица диагностики объёмной передачи показывает короткий итог; замеры напрямую, через nfqws2 и детали подбора стратегии раскрываются отдельно.
- Для коротких HTTP-ответов можно отдельно включить тестовый POST с телом до 64 КБ на введённых пользователем доменах. Тайм-аут POST отмечается отдельно и не считается доказанным обрывом входящей передачи.

## Проверки

- Backend: `cargo fmt --check` и `cargo test --locked` прошли локально.
- Frontend: 316 тестов, TypeScript-проверка и production-сборка прошли локально.
- GitHub Actions выполняет полный релизный набор проверок и ARM64-сборку.
- Проверку на роутере не выполнял; её проводит пользователь.
