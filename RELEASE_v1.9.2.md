# v1.9.2 — Последовательный диагноз блокировки

## Изменения

- Проверки в «Диагнозе блокировки» идут в ожидаемом порядке: DNS, TCP 443, прямой запрос, SNI, HTTP, текущий маршрут nfqws2 и QUIC.
- Каждый результат появляется сразу после соответствующего реального запроса; индикатор показывает текущий шаг.
- Ошибка отдельной пробы больше не прекращает весь диагноз — следующие проверки продолжаются, итоговое заключение показывается сверху.
- Увеличен размер текста результатов для лучшей читаемости.

## Проверки

- 401 frontend-тест.
- TypeScript typecheck и production build.
- Rust fmt, полный тестовый набор и Clippy.
- Release workflow проверяет shell-скрипты, аудит зависимостей и ARM64 Linux musl сборку.
