# v1.2.2

- Добавлено редактирование штатных настроек UDP и HTTP/HTTPS по IP и сайтам с сохранением соответствующих переменных конфигурации.
- Сохранение штатных настроек ограничено допустимыми группами и проходит проверку nfqws2 с резервной копией и откатом при ошибке.
- Пользовательские аргументы и добавленные стратегии сохраняют построчное форматирование в `NFQWS_ARGS_CUSTOM`.

## Интерфейс и профили

- Навигация конструктора объединена с разделом «Конфигурация».
- Удалён дублирующий сводный текст перед редактором профиля. Справочник nfqws2 теперь справа, свёрнут при первом открытии и раскрывается по нажатию; на узком экране он следует после редактора.
- Штатные UDP и HTTP/HTTPS группы редактируют исходные переменные конфигурации, с проверкой и резервным восстановлением при ошибке. Связь `NFQWS_EXTRA_ARGS` с `MODE_*` нельзя случайно затереть редактором.
- В конструкторе добавлен выбор параметров из справочника установленного nfqws2, русские пояснения, режим редактирования Lua шагов и сохранение переноса строк в пользовательской стратегии.

## Проверки

- Frontend: 31 файл, 292 теста пройдены; `pnpm run build` завершился успешно.
- Backend: `cargo fmt --check`, полный `cargo test --locked` и `cargo clippy --all-targets -- -D warnings` завершились успешно. Rust target cache находится на диске E:.
- Локальная Chromium-проверка с mock API подтвердила отображение профилей, редактора штатного UDP-профиля и свёрнутого справочника. Содержимое справочника открывается по нажатию. Mock API не проверяет реальные изменения на роутере.
- Безопасная read-only проверка роутера подтвердила, что там работает nfqws2 и установлена панель v1.2.1. Тестовую v1.2.2 на роутер не устанавливали.
