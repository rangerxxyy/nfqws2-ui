# v1.12.0 — Автоподбор стратегий в мониторинге

В мониторинг добавлена отдельная вкладка автоподбора. Она связывает результаты текущих проверок сайтов с существующим ограниченным HTTPS-подбором стратегии.

## Что нового

- Можно включить автоподбор, задать число последовательных ошибок (2–4) и паузу между попытками (6–24 часа).
- Подбор запускается только для домена из мониторинга, который ранее открывался, после повторной проверки через пять минут. Одновременно работает не более одной операции.
- Массовые отказы, DNS/маршрутные ошибки, маршруты Podkop, остановленный nfqws2 и временно занятая диагностика не приводят к немедленному подбору; временные препятствия повторяются с паузой.
- Найденные подтверждённые варианты видны в мониторинге и открываются в существующем интерфейсе результата подбора.
- Автоприменение можно отдельно разрешить. По умолчанию оно выключено. При включении добавляется отдельный профиль `NFQWS_ARGS_CUSTOM` для домена; существующий профиль этого домена автоматически не заменяется.
- Перед применением проверяются конфигурация и `nfqws2 --dry-run`. Изменение проходит через существующую резервируемую транзакцию с перезапуском, проверкой целевого сайта и ранее доступных сайтов и автоматическим откатом, если проверка не прошла.
- Состояние ограничено по размеру и числу записей; интерфейс показывает активную проверку, варианты и журнал событий.

## Проверки

- Frontend: `pnpm build`; все 481 теста проходят.
- Backend: `cargo test`; полный набор проходит.
- CI, ARM64 cross-build и аудит зависимостей должны завершиться до публикации GitHub Release.
- Проверка на Netcraze Hopper NC-3811 с KeeneticOS не проводилась.

## Ограничения

- Подбор сейчас запускается для HTTPS (TCP/443); он использует установленный Lua-каталог и текущие проверки стратегий.
- Автоматическое изменение конфигурации требует отдельного включения и явного подтверждения в интерфейсе.
- Профили, уже настроенные для домена, сохраняются; автоприменение такого результата будет пропущено и причина появится в журнале.
- Автоподбор не доказывает наличие DPI и не обещает обход блокировки; это диагностический подбор по результатам доступности.
