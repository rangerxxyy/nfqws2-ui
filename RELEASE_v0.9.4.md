# v0.9.4 — Импорт сторонней конфигурации из TXT

- В разделе «Проверка сторонней конфигурации» теперь можно выбрать файл `.txt` наряду с `.conf`; регистр расширения не важен.
- Содержимое добавляется в список вариантов и проходит тот же безопасный статический разбор и проверку, что и `.conf`.
- Сохраняется ограничение размера файла 64 КиБ.
- Проверены допустимые и недопустимые расширения, HTML разметка формы и метаданные релиза.

## Сверка с Zemidala

Сверено с Zemidala v1.22.3. Свежие изменения Zemidala в обработке ошибок и установке PHP-модуля cURL относятся к его PHP/OpenWrt-архитектуре. В nfqws2-UI запросы и ошибки обрабатываются Rust backend; перенос этих изменений не подходит. Проверка новых совместимых UI-возможностей продолжается после выпуска.

## Проверки

- Frontend: Vitest, TypeScript typecheck и production build.
- Backend: Rust tests, formatting и Clippy.
- Shell/installer preflight и структура release package проверяются GitHub Actions.
- Проверка на физическом роутере не проводилась.
