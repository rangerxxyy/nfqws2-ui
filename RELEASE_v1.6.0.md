# v1.6.0 — Свободное место для снимков

## Изменения

- Страница снимков показывает, сколько места осталось на разделе с архивами.
- Если свободного места меньше максимально допустимого размера архива (64 МиБ), панель предупреждает, что новый снимок может не поместиться.
- Измерение выполняется чтением `statvfs`; оно не создаёт и не удаляет файлы. На системах без такого измерения показывается понятный статус «не удалось определить».

## Проверки

- 393 frontend-теста.
- TypeScript typecheck и production build.
- Rust formatting и полный набор тестов: 176 библиотечных, 200 бинарных и 53 интеграционных. На Linux отдельно проверяется получение свободного места во временной файловой системе.
- Clippy и cargo audit.
- Полный release workflow дополнительно проверяет установщик, зависимости и ARM64-сборку.
