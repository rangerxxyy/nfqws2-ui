# nfqws2-ui v0.7.3

## Изменения

- Убрана глобальная синяя подсветка выделения текста, из-за которой выбранный текст в редакторе списков и других местах выглядел как сплошная синяя заливка во всех палитрах.
- Убрана фоновая подложка выделения текста во всех палитрах; выделение остаётся функциональным для редактирования и копирования.
- Для синтаксического редактора сохранено цветное отображение конфигурации при выделении текста.

## Проверки

- Все frontend-тесты и production-сборка прошли.
- Упаковка и ARM64-сборка проверяются в GitHub Actions.
- В браузере и на роутере визуальная проверка не проводилась.
