# v1.3.3 — Конструктор стратегий

- Чипы параметров в конструкторе стали компактнее и получили мягко различающиеся фоны, границы и цвета ключа/значения. Разделитель `=` выровнен, чтобы значение не смещалось относительно ключа.
- Выровнена раскладка фильтров и шагов, подправлены размеры контролов и перенос длинных имён параметров. Справочник параметров убран из редактора, чтобы освободить место.
- Добавлено перетаскивание стратегий за свободную область карточки с подсветкой позиции и анимацией перестановки. Поля, кнопки и элементы ввода не запускают перетаскивание; новый порядок сохраняется в профиле.
- Номера стратегий теперь идут подряд по порядку директив `lua-desync` и пересчитываются при добавлении, удалении и перемещении.

Проверено локально: frontend-тесты, проверка TypeScript и production build. Rust-тесты и кросс-сборка для роутера выполняются release workflow GitHub Actions. На роутере и в Firefox отдельно не проверялось.
