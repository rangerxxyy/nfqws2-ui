# v1.5.9 — Контроль места для снимков

## Изменения

- На странице резервных копий можно задать максимальное количество локальных снимков, срок хранения и общий лимит их объёма.
- Стандартный лимит — 512 МиБ. При превышении лимита система очищает старейшие незакреплённые локальные копии, сохраняя минимум пять снимков.
- Закреплённые копии не удаляются автоматически. Если они занимают больше лимита, интерфейс показывает величину превышения.
- Существующие установки получают значение 512 МиБ автоматически; настройки NAS и текущий режим автоматических копий сохраняются.

## Проверки

- 389 frontend-тестов.
- TypeScript typecheck и production build.
