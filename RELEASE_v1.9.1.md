# v1.9.1 — Компактная проверка обрыва

## Изменения

- Раздел «Обрыв на 16 КБ» перестроен в компактную форму, карточку текущего этапа и список сетей — по ориентиру Zemidala, сохраняя цветовую тему, акценты и читаемый шрифт nfqws2-ui.
- Прогресс показывает текущую сеть и счётчик проверок. Результаты появляются по мере работы и содержат сеть/адрес, ASN, статус и раскрывающиеся детали замеров.
- В «Диагнозе блокировки» этапы DNS, TCP 443, текущий маршрут, прямой запрос, SNI, HTTP и QUIC теперь поступают из backend по мере завершения реальных проб; убрано проигрывание фиктивного прогресса после готового отчёта.
- На узком экране строки результатов перестраиваются; длинные домены и адреса переносятся.
- Сохранены проверка POST-ответов, остановка, просмотр/применение найденной стратегии и присоединение сети к профилю.
- Кнопки «Что изменилось» и «Откатить» в истории размещены непосредственно под именем изменённого файла.

## Проверки

- Полный набор frontend-тестов.
- TypeScript typecheck и production build.
- Rust `cargo fmt --check`, полный Rust test suite и `cargo clippy --all-targets -- -D warnings`.
- Release workflow проверяет shell-скрипты, аудит зависимостей и сборку ARM64 Linux musl.
