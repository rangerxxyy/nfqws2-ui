# nfqws2-ui v0.7.1

## Изменения

- В редактор добавлена кнопка «Оформить» для безопасного форматирования простых значений `NFQWS_ARGS*`: каждый параметр переносится на новую строку, между группами `--new` добавляется отступ.
- Результат остаётся черновиком и не записывается на роутер, пока пользователь отдельно не применит конфигурацию.
- Shell-подстановки, экранирование, вложенные кавычки и повреждённые присваивания отклоняются, чтобы форматтер не менял смысл конфигурации.
- Текстовые символы уведомлений заменены контурными Tabler Circle Check и Alert Circle, используемыми XKeen UI.
- «Диагноз блокировки» показывает PTR-имена для IP-адресов сайта через доступные `kdig`, `dig` или `nslookup` (до четырёх адресов); отсутствие PTR не влияет на остальные проверки.

## Проверки

- Web: 182 теста, production build.
- Backend: полный locked test suite, `cargo fmt` и Clippy с запретом предупреждений.
- Локальная проверка в браузере и проверки на роутере не проводились.
