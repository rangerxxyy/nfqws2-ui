# v0.8.4 — Поддержка GitHub blob-ссылок

- Проверка сторонней конфигурации `.conf` теперь принимает обычные ссылки GitHub вида `github.com/owner/repo/blob/branch/file` и преобразует их в raw URL перед загрузкой.
- Сохранены ограничения безопасной загрузки: HTTPS, публичный IPv4 с DNS pinning, без редиректов, лимит 64 КиБ.

## Проверки

- Rust: 275 тестов, форматирование и Clippy.
- Web: 201 тест, TypeScript, production-сборка и `pnpm audit --prod`.
- Роутерная проверка не проводилась.
