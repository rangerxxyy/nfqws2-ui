# v1.9.9 — Удобный выбор интерфейса и более надёжные обновления

## Изменения

- Выбор `ISP_INTERFACE` стал обычным выпадающим списком браузера. В нём сначала показаны интерфейсы маршрута по умолчанию, затем текущая настройка и остальные обнаруженные сетевые интерфейсы. `lo` больше не помечается как выход в интернет. Если нужного интерфейса нет в списке, его можно ввести вручную и применить кнопкой или Enter. Список не пропадает при редактировании конфига.
- В окне обновлений отображаются 10 последних релизов nfqws2-UI и nfqws2. Кнопка «Обновить» обходит кэш; каталог сохраняется на роутере на 4 часа. Если основной GitHub API недоступен, используются резервные маршруты.
- В «Проверке сторонней конфигурации» добавлен прокручиваемый просмотр содержимого добавленных файлов и текста.
- Сжат вертикальный интервал в итогах «Диагностики блокировки». Исправлен акцентный ореол фокуса, который выглядел как фиолетовая полоса при выделении текста в редакторах.
- В отчёт для помощи добавлены архитектура, версия nfqws2, память, загрузка CPU и состояние правил перехвата.

## Проверки

- Полный frontend test suite, TypeScript typecheck и production build.
- Полный Rust test suite, Rust fmt и Clippy.
- Release workflow проверит shell preflight, security audit и ARM64 Linux musl cross-build перед публикацией.
