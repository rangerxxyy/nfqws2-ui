# v0.9.6 — Получение обновлений и проверка стратегий

- Список версий панели загружается короче, чтобы быстрее открываться на роутерах с медленным соединением.
- Увеличено время ожидания ответа GitHub; размер ответа и таймаут показываются разными сообщениями.
- Результаты каталога не влияют на режим, который проверяет только собственные стратегии.
- Результаты проверки доменов выровнены; время ответа выделено бирюзовым цветом.
