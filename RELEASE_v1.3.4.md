# v1.3.4 — Полировка конструктора профилей

- Убран курсор захвата с карточек стратегий. Он отображается только на ручке перетаскивания, поэтому работа с параметрами не путается с перемещением карточки.
- Сегменты ключа и значения в параметрах получили отдельные мягкие фоны и тонкие границы, одинаковую высоту и компактное выравнивание. Знак `=` между ними не выводится.
- Имя профиля редактируется прямо в поле «Имя» без карандаша и модального окна. Заголовок обновляется сразу; имя пользовательского профиля сохраняется в аргументах профиля, штатного — в локальном хранилище браузера.

Проверки перед выпуском: frontend-тесты, TypeScript typecheck/build, Rust tests/clippy/fmt и release workflow GitHub Actions. Проверка на физическом роутере не выполнялась; пользователь проверит её самостоятельно.
