# v1.11.8 — Выравнивание выделения и статуса проверки списков

Основной редактор конфигурации использует межстрочный интервал `1.5`, совпадающий с настройкой XKeen UI. Это согласует геометрию строк с фоном выделения CodeMirror и сохраняет единый слой текста и выделения.

Для списков панель отдельно показывает результат определения использования в профилях и решение backend о проверке формата. Если профильный разбор недоступен, но в аргументах конфигурации ссылка на список не найдена, оба состояния отображаются без потери второго результата.

Проверки: 432 frontend-теста, production-сборка; 281 Rust-тест, `cargo fmt --check` и Clippy.
