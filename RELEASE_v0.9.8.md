# v0.9.8 — Поиск сети по домену или IP

- Генератор ASN принимает номер автономной системы, публичный IPv4 или домен.
- Для домена или адреса определяется сеть через RIPEstat, после чего IPv4-префиксы добавляются в `ipset.list`.
- Быстрые значения популярных ASN заполняют поле поиска; запись выполняется после нажатия основной кнопки.
