# v1.11.9 — Более частая проверка релизов

Панель автоматически обновляет статусы nfqws2-UI и nfqws2 раз в две минуты, пока вкладка открыта. Серверный кэш последних десяти релизов UI и ядра также имеет двухминутный срок, поэтому новый выпуск появляется без ручного нажатия кнопки обновления.

Если GitHub временно недоступен, используется сохранённый список, а следующая попытка откладывается на десять минут.

Во время диагностики структура и размер карточки результатов остаются стабильными. Пользовательское поле стратегий подсвечивает аргументы той же палитрой, что и редакторы конфигурации. Выделение в редакторах использует отдельную синюю заливку и не зависит от выбранного акцента; убрана цветная граница линейки. Окно обновлений сверено с XKeen UI по высоте, ширине, прокрутке списка, шрифтам и расположению кнопки установки; подпись о периоде опроса удалена.

Проверки: 434 frontend-теста, production-сборка; 476 Rust-тестов, `cargo fmt --check` и Clippy.
