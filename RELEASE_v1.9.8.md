# v1.9.8 — Меньше запусков iptables при проверке статуса

## Изменения

- Проверка подключённых NFQUEUE-хуков получает полный снимок таблицы `mangle` одним вызовом `iptables -w -t mangle -S`, вместо четырёх отдельных запусков. Это уменьшает число процессов на роутере при обновлении кэша статуса.
- Сохранено 20-секундное окно после перестройки firewall: временно отсутствующие хуки в это время не показываются как ошибка.
- В «Проверке сторонней конфигурации» можно за раз выбрать несколько файлов `.conf`/`.txt`; файлы добавляются по одному с сохранением лимита 10 конфигов за проверку и размера до 64 КиБ на файл.
- Кнопка применения прошедшей конфигурации поднята в строку заголовка результата, чтобы сравниваемые списки сайтов начинались на одном уровне.
- Выделение текста в цветных редакторах больше не цепляет нижний слой подсветки и подсвечивается цветом выбранного акцента.

## Проверки

- Rust tests, fmt и Clippy.
- Frontend tests, TypeScript и production build.
- Shell preflight, security audit и cross-build ARM64 Linux musl в GitHub Actions.
