# v1.9.4 — Понятная причина пропуска SNI

## Изменения

- Если прямую проверку не удалось выполнить, например отсутствует `curl`, этап SNI больше не указывает ошибочно на контрольное имя. Вместо этого выводится причина пропуска сравнения.

- 403 frontend-теста.
- TypeScript typecheck и production build.
- Rust fmt, полный тестовый набор и Clippy.
- Release workflow проверяет shell-скрипты, аудит зависимостей и ARM64 Linux musl сборку.
