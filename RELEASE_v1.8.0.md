# v1.8.0 — Надёжное применение конфигурации

## Изменения

- Если конфигурация во время проверки или подтверждения уже стала равна текущему черновику, повторная запись и перезапуск не выполняются.
- Если backend получил более новую ревизию с другим содержимым, панель отменяет применение устаревшего черновика и просит перечитать конфигурацию.
- Безопасные ссылки `NFQWS_EXTRA_ARGS` на определённые в этом же файле `$MODE_LIST`, `$MODE_AUTO` и `$MODE_ALL` больше не вызывают ложное предупреждение о неразрешаемой shell-переменной. Для неизвестных shell-переменных предупреждение сохраняется.
- Добавлены регрессионные проверки для сравнения ревизий конфигурации, safe mode-ссылок и регистрации кнопок confirmation-окна.

## Проверки

- 399 frontend-тестов.
- TypeScript typecheck и production build.
- Rust `cargo fmt --check`, 437 тестов Rust по всем целям и `cargo clippy --all-targets -- -D warnings`.
- Release workflow проверяет shell-скрипты, аудит зависимостей и сборку ARM64 Linux musl.
