# v0.8.0 — Компактная форма автоподбора и читаемое уведомление об обновлении

- Авто-подбор стратегии получил компактную раскладку с подписями слева и настройками справа; на мобильном экране форма переходит в одну колонку.
- Контурная галочка уведомления об обновлении теперь корректно отображается как SVG.
- Текст версии выровнен под заголовком уведомления по примеру XKeen UI.
- Ответы API в неверном формате отображаются в виде понятной ошибки с коротким фрагментом ответа сервера.

- Production-сборка веб-интерфейса прошла локально.
