# v0.8.1 — Два вида редактора списков

- В «Списках» можно переключаться между текстовым редактором и построчным видом; выбор запоминается в браузере.
- В построчном виде можно искать строки и удалять их по одной или выбором нескольких. Изменения остаются черновиком до явного применения.
- Оба вида используют один черновик, сохраняя комментарии, порядок записей и окончания строк при переключении.
- Построчный вид адаптируется к мобильному экрану и цветам тёмной, светлой и неоновой тем.
- Содержит также изменения v0.8.0: компактную раскладку автоподбора, исправление иконки уведомления и понятную ошибку для ответов API не в JSON.
