# v1.5.2 — Палитры, диагностика и обновление nfqws2

## Изменения

- Добавлена плашка доступного обновления ядра nfqws2 рядом с уведомлением обновления панели. Выбор версии использует штатное окно обновления; закрытая плашка возвращается для следующего тега.
- Все успешные toast-подтверждения, включая «nfqws2 перезапущен», используют белую SVG-галочку.
- Редактор групп конфигурации использует общую подсветку с полным редактором: ключи параметров и их значения имеют отдельные цвета; длинные Lua-параметры не теряют выравнивание.
- Добавлены настраиваемые предупреждения конфигурации и согласована подсветка навигации, popup-select и фокуса с темой и акцентом.
- Диагностика сайта сверяет только активные списки; выполненные этапы показывают фактическую длительность. Неисполненные шаги не получают фиктивных результатов.
- Добавлено предупреждение для маршрута Podkop FakeIP в результатах подбора. DNS-проверки имеют ограничение по времени и объёму.
- Сохранены и проверены выбранный способ доставки Telegram и условные поля интерфейса/прокси.
- В стратегиях сообщества компактнее показаны статусы качества/свежести, скрытые цели и результаты копирования.

## Проверки перед выпуском

- Frontend: 375 тестов, `pnpm --dir web typecheck`, `pnpm --dir web build`.
- Backend: `cargo test --locked` (413 тестов), `cargo fmt --all -- --check`, `cargo clippy --all-targets --locked -- -D warnings`, `cargo check --target aarch64-unknown-linux-musl --locked`.
- Зависимости: `pnpm --dir web audit --prod` и `cargo audit --file backend/Cargo.lock`.
- В Chromium с локальным mock API проверены общий экран, редакторы групп и смена акцентной палитры при переходе в раздел сообщества. Mock API использовал старую схему данных и не является проверкой backend; временная вкладка и процессы закрыты.
- На роутере выполнен один read-only `GET /api/health` по адресу панели: HTTP 200, `{"ok":true,"service":"nfqws2-ui"}`. Это проверка работающей установленной панели, не кандидатного бинарника. Диагностик и нагрузочных сетевых тестов не запускалось; временные файлы на роутере не создавались.

## Ограничения

- Результаты community/history на локальном preview нельзя считать backend-проверкой: mock API несовместим с текущей схемой этих разделов.
- ARM64/musl проверен командой `cargo check`; готовый release archive и SHA-256 должны быть подтверждены release workflow после публикации тега.
