# v1.10.0 — Исправленный выбор интерфейса и упрощённая навигация

## Изменения

- Выпадающий список `ISP_INTERFACE` использует фирменную палитру UI и показывает распространённые имена `eth*`, `ppp*`, `pppoe*`, `wan*`, обнаруженные интерфейсы и текущее значение. Пункта «Интерфейс не задан» нет; ручной ввод доступен последним.
- Из навигации удалены разделы «Диагностика 16 КБ», «Файлы после обновлений» и «Отчёт для помощи».
- В результатах проверки сетей показывается только домен без пути к файлу; текст адреса и ASN увеличен.
- Меню выбора учитывает активные цвета и палитру оформления.

## Проверки

- Frontend: 426 тестов, TypeScript typecheck и production build.
- Release workflow проверит backend Rust, установочные сценарии, аудит зависимостей и ARM64 Linux musl cross-build.
