# v1.11.4 — Убран лишний перерендер структуры при выделении

При движении курсора структура конфигурации справа больше не разбирается и не строится заново. Пересчёт выполняется только при изменении текста, активный пункт обновляется двоичным поиском по смещениям. Обработчик изменения конфигурации объединён: ранее одно событие CodeMirror обновляло панель дважды.

Сверено с Zemidala: список структуры обновляется при вводе, а смена позиции каретки обновляет статус/подсказку без повторного построения списка.

Проверки перед публикацией: 428 frontend-тестов и production build. Release workflow проверит backend, установщик и ARM64-сборку.
