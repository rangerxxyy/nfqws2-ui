# v1.2.5 — Исправление прокрутки конструктора профилей

- Восстановлена компактная раскладка конструктора из v1.2.3. Список профилей остаётся закреплённым при прокрутке содержимого стратегии.
- Прокрутка стратегий работает пальцем и мышью в отдельной области редактора на широких и узких экранах.
- Названия профилей и подписи больше не обрезаются многоточием: текст переносится по строкам.
- Переименование и визуальная перестановка профилей сохранены. После удаления пользовательского профиля имя и порядок оставшихся профилей остаются привязаны к правильным профилям.

## Проверки

- На ПК: 306 frontend-тестов, TypeScript-проверка и production-сборка.
- Rust-проверки и ARM64-сборка выполняются релизным workflow GitHub Actions.
- Роутерное тестирование выполняет пользователь.
