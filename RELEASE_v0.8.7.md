# v0.8.7 — Адаптация путей сторонних `.conf`

- При проверке сторонней конфигурации пути к `--hostlist`, `--hostlist-exclude`, `--ipset` и `--ipset-exclude` из известных раскладок nfqws/nfqws2 и zapret сопоставляются с файлами в каталоге списков текущей установки.
- Для защиты роутера разрешаются только существующие обычные файлы внутри каталога списков. Неизвестные абсолютные пути, отсутствующие файлы, обход каталога и символические ссылки отклоняются до запуска тестового процесса.
- `--hostlist-auto` копируется из пути проверяемого конфига после безопасного сопоставления; если исходный файл недоступен в активном каталоге списков, проверка использует пустую временную копию, как Zemidala. `--hostlist-auto-debug` отключён; копирование ограничено 4 МиБ.

## Проверки

- Rust: 278 тестов, форматирование и Clippy.
- Web: 201 тест, TypeScript, production-сборка и `pnpm audit --prod`.
- ARM64 сборка и release workflow проверяются GitHub Actions; тестирование на физическом роутере в этой среде недоступно.
