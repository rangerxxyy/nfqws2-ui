# v1.0.2 — Компактная навигация и настройка входа

- Добавлен переключаемый компактный режим навигации с шестью группами страниц.
- Страница сообщества снова доступна в меню панели.
- Срок «Запомнить меня» теперь настраивается в разделе «Настройки UI»; на экране входа осталась галочка, которая включает или отключает запоминание для этого устройства.
