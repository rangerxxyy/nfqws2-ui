# v1.11.0 — Надёжное выделение текста

Основной редактор конфигурации переведён на CodeMirror 6, как в XKeen UI. Один редактор теперь отвечает за текст, подсветку синтаксиса, номера строк, прокрутку и выделение; прежнее наложение `textarea` поверх `pre` удалено. Сохранены цвета палитры, перенос строк, синхронизация черновика, копирование, переходы из предупреждений и быстрых параметров.

Редакторы аргументов по группам тоже переведены на CodeMirror, чтобы сохранить подсветку токенов и палитру без наложения второго текстового слоя. Как в Zemidala, подсветка отключается для текста конфигурации больше 200 КБ, чтобы большие вставки не нагружали интерфейс.

Проверки перед публикацией: frontend tests и production build; полный release workflow запускает Rust, installer, audit и ARM64 проверки.
