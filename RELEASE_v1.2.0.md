# v1.2.0 — Расширенный конструктор профилей

- Добавлен конструктор runtime-профилей nfqws2: фильтры, списки доменов и IP, типы пакетов и упорядоченные Lua-шаги.
- Параметры nfqws2 и типы трафика определяются по установленной версии; Lua-функции и параметры — по установленным скриптам.
- Если справка `nfqws2 --help` на роутере неполная или медленная, каталог перечитывается с увеличенным тайм-аутом; полнота списка показывается в разделе профилей.
- Добавлены создание, копирование, переименование, изменение порядка аргументов и вставка профиля из текста.
- Добавлены справка по параметрам, предупреждения о несовместимых аргументах и возможном перекрытии правил.
- Применение профиля проверяет конфигурацию, сохраняет резервную копию и возвращает прежнюю конфигурацию, если перезапуск не прошёл.
- В журнале можно очистить выбранный источник после подтверждения.
- Вспомогательная команда резервного копирования панели переименована, чтобы не пересекаться с другим UI.
