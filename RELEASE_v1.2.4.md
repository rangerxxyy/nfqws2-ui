# v1.2.4 — Удобнее профили и мобильная навигация

- Список профилей и справочник параметров остаются на месте при прокрутке редактора стратегий. Профили можно переименовывать и менять их визуальный порядок; это не меняет порядок обработки nfqws2.
- Из конструктора убран встроенный профиль «HTTP/HTTPS по IP». Пользовательские профили с таким же названием сохраняются в списке.
- В разделе списков инструменты удаления строк, импорта и экспорта перенесены в меню «Ещё», чтобы освободить место для содержимого.
- На телефонах страницу можно прокручивать пальцем целиком, включая область навигации.
- Успешные действия запуска, остановки и перезапуска nfqws2 показывают короткий статус вместо технического вывода службы.

## Проверки

- На ПК: 304 frontend-теста, TypeScript-проверка и production-сборка.
- Проверки Rust и сборка ARM64 выполняются релизным workflow GitHub Actions.
- Роутерное тестирование этого релиза не выполнялось; пользователь проверит его самостоятельно.
