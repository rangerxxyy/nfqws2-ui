# v0.9.5 — Удобства редактора конфигурации

- Установщик повторяет загрузку архива и SHA-256 с обходом кэша CDN при временном несовпадении файлов.
- Исправлено получение списка версий панели: запрос использует тот же выбор wget, что и проверка релизов nfqws2.
- Ошибка запуска внешней утилиты, используемой мониторингом, больше не подменяется ложным сетевым отказом.
- Исходное сообщение backend показывается в итоговом статусе; этапы TCP/TLS/HTTP и передачи помечаются недоступными, если проверку невозможно запустить.
- В редактор добавлены кнопка очистки с отдельным предупреждением и разворачивание почти на весь экран с плавной анимацией.
- Очистка меняет только черновик; применение к службе остаётся отдельным действием.
- Страницы «Отчёт для помощи» и «Резервные копии» временно скрыты из интерфейса.
- В разделе «Проверка сторонней конфигурации» поддерживается импорт `.txt` наряду с `.conf`.
