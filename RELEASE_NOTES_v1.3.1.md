# v1.3.1 — Полировка UI/UX и фиксы разделов

- Копирование конфигурации и кнопки «Копировать»/«Применить».
- Переключение `ISP_INTERFACE` с сохранением выбранного значения.
- Удаление «Справочника флагов nfqws2» из настроек конфигурации.
- Переименование профиля в «Конструкторе стратегий».
- Удаление «QUIC по сайтам» из списка конструктора.
- Полные подписи `.list`, включая имя файла.
- Единый стиль кнопок по референсу XKeen UI.
- Метка `NFQWS_ARGS_CUSTOM` или соответствующей переменной под названием профиля.
- Удаление лишних подсказок из «Списков доменов и IP».
- Общие токены шрифта, палитры и типографической иерархии.
- Доступные UI-диалоги вместо браузерных подтверждений.

Тестирование проведено на ПК в Chromium и Firefox, а также точечно на роутере; конфигурация nfqws2 не менялась, служба не перезапускалась.
