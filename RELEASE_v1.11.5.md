# v1.11.5 — Убрана полоса активной строки в редакторах

В CodeMirror отключён стандартный фон активной строки, который создавал дополнительную полосу при перемещении курсора и выделении текста. Цвет выделенного пользователем диапазона остаётся привязан к текущей палитре.

Сверено с XKeen UI и проверено в браузере: многострочное выделение видно, активная строка не закрашивается второй полосой.

Проверки перед публикацией: 428 frontend-тестов и production build. Release workflow проверит backend, установщик и ARM64-сборку.
