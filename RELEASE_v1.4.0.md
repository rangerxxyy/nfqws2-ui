# v1.4.0 — Мониторинг, редактор списков и конструктор стратегий

## Изменения

- Исправлен выбор основной Lua-функции стратегии: изменение в нативном `select` обновляет аргумент профиля.
- В редакторе списка режим «Текстом / Списком» выбирается через стилизованный popup-select; «Удалить дубли» находится под `⋯`.
- Раздел мониторинга уплотнён: компактные карточки, видимый статус, история проверок и раскрываемые технические этапы.
- Проверка нового домена запускается после сохранения. Ошибки API отображаются в статусе и toast.
- Сохранение и удаление домена передаёт актуальный интервал мониторинга.
- После неуспешной проверки основного адреса выполняется одна повторная HTTPS-проба на альтернативный публичный IPv4.

## Сверка проверки мониторинга с Zemidala

Обе реализации выполняют HTTPS GET с ограничением передачи до 64 КиБ и контрольный POST с телом 64 КиБ, если GET завершился коротким ответом. POST не считается доказательством блокировки сам по себе: предупреждение ставится только при тайм-ауте после установки TLS. В предыдущей версии Rust проверялся только первый IPv4 из DNS; теперь проверяется максимум два публичных IPv4. SSRF-фильтр сохранён.

## Проверки

- Frontend: 338 тестов, TypeScript typecheck и production build.
- Backend: Rust unit/integration tests, `cargo fmt --check` и `cargo clippy -- -D warnings`.
- Визуальная проверка в актуальной панели и проверка на роутере не выполнялись: доступная локальная API-среда сообщает v1.2.2. Пользователь сможет проверить релиз на своём роутере.
