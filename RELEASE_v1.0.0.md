# v1.0.0 — Общая стратегия для сайтов и защита панели

- В авто-подборе можно проверить один сайт или список из 2–15 сайтов. Для списка подбирается один общий профиль; в него попадают только домены, подтвердившие стратегию.
- Добавлена очистка завершённой истории подборов с сохранением текущих проверок.
- В «Настройки и оформление UI» оформление и настройки панели разделены на два подраздела.
- Добавлена опциональная защита панели паролем и вход с выбором срока «Запомнить меня»: 1, 7, 30, 90, 365 дней или «Никогда».
- Улучшены команды в разделе «О nfqws2-UI»: понятнее описаны действия, добавлено подтверждение копирования.
- Прокрутка конфигурации синхронизируется с кадром браузера для более плавного отображения.
- Добавлен раздел стратегий сообщества с загрузкой вариантов с роутера.
